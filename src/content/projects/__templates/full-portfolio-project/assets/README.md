# Project Assets

Place project-specific body assets here after copying the template into a real project folder.

Recommended naming:

figure-01-descriptive-name.jpg
figure-02-descriptive-name.png
figure-03-descriptive-name.webp
before.jpg
after.jpg

The project root should normally contain:

thumbnail.jpg
hero.jpg
project.ts

The `assets` folder should normally contain body figures and comparison imagery.

Do not use meaningless filenames such as:

image1.png
final2.jpg
new-map-final-final.png

Prefer filenames that still make sense when viewed outside the project page.
